## Выпускная квалификационная работа

### [Attention Meta-Learner for MOEX Si Futures](https://github.com/Boo4kin/attention-meta-learner-moex)

Исследовательский проект по краткосрочному прогнозированию направления цены фьючерса Si на Московской бирже.

- **Данные:** 219 529 минутных OHLCV-баров и 29 признаков.
- **Модели:** CatBoost, LightGBM, экспериментальные KAN/Mamba-proxy и attention-мета-модель.
- **Проверка:** временной holdout, purged cross-validation и векторизованный бэктест; результаты доступны через Streamlit.

> Метрики проекта относятся к историческому исследовательскому бэктесту и не являются подтвержденной доходностью реальной торговой системы.
