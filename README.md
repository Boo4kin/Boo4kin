### [Attention Meta-Learner for MOEX Si Futures](https://github.com/Boo4kin/attention-meta-learner-moex)

ВКР 2026 года по краткосрочному прогнозированию направления цены фьючерса Si на Московской бирже.

Проект объединяет подготовку минутных OHLCV-данных, построение признаков, несколько базовых моделей, attention-мета-модель, временную валидацию, бэктест и Streamlit-интерфейс. Репозиторий содержит текст ВКР, презентацию, исследовательский ноутбук и воспроизводимый код эксперимента.

> Результаты относятся к исследовательскому историческому тестированию и не являются подтвержденной доходностью торговой системы.
