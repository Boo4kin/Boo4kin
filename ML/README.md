# Machine Learning

Учебные ноутбуки по классическому машинному обучению.

## Темы

- feature selection и подготовка признаков;
- polynomial features;
- SVM;
- k-nearest neighbours;
- метрики качества;
- выбор порога классификации;
- диагностика моделей;
- интеграция и подготовка данных.

Материалы относятся к университетской учебной практике.
