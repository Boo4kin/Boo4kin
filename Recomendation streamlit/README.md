# Recommendation System

Учебный проект рекомендательной системы с интерфейсом на Streamlit.

В репозитории сохранён код подготовки данных по книгам, пользователям и рейтингам, а также архив с основной версией приложения.

## Стек

Python · pandas · Streamlit

Проект выполнен в рамках университетской практики и сохранён в исходной структуре.
