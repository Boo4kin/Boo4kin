# Computer Vision

Подборка учебных Jupyter Notebook по компьютерному зрению.

## Темы

- instance segmentation с Mask R-CNN;
- object detection с Faster R-CNN и SSD;
- semantic segmentation с U-Net;
- подготовка image datasets в PyTorch;
- трекинг объектов с DeepSORT и ByteTrack;
- морфологические операции и частотные методы.

Материалы выполнены в рамках обучения в Финансовом университете и сохранены как учебная практика.
